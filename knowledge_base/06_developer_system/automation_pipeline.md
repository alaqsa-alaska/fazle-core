# Automation Pipeline

## Purpose
Define safe automation boundaries.

## Auto Allowed
- Clear candidate FAQ.
- Safe employee policy answer.
- Non-sensitive office/contact answer.

## Draft/Admin Required
- Payment.
- Attendance finalization.
- Escort confirmation.
- Release slip ambiguity.
- Unknown identity.
- Sensitive/internal request.

## Maintenance
Expire old pending drafts after 48 hours unless admin marks hold.
